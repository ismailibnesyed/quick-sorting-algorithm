# ⚡ Quick Sort Visualizer & Learning App

একটি সহজ, শিক্ষণীয় ও ইন্টারঅ্যাক্টিভ **Quick Sort Visualizer**, যা নতুনদের জন্য একদম সহজ ভাষায় তৈরি করা হয়েছে।

---

## 🌟 প্রধান সুবিধাসমূহ (Features)

1. **🔄 মার্জড কন্ট্রোল প্যানেল (Side-by-Side Unified Controls):**
   - ইনপুট বক্স, প্রিসেট বাটন (`সহজ [৫টি]`, `Textbook`, `Sorted`, `Reverse`, `Random`), প্লেব্যাক কন্ট্রোল (`Play`, `Pause`, `Next`, `Prev`, `Reset`), স্পিড (`0.6x`, `1x`, `2x`), কাউন্টার এবং টাইমলাইন স্ক্রাবার—সবকিছু পাশাপাশি মার্জ করা হয়েছে।

2. **💡 সহজ ও সংক্ষিপ্ত ব্যাখ্যা (Easy & Minimal Text):**
   - বড় বড় প্যারাগ্রাফের বদলে একদম সহজ ১-২ লাইনের ব্যাখ্যা ও টিপস।
   - কেন `i` থামল? কেন `j` থামল? কখন Swap হলো? এবং কীভাবে পিভট লক হলো—সহজ বাংলায় স্পষ্ট করে বলা হয়েছে।

3. **💻 সম্পূর্ণ কোড ইমপ্লিমেন্টেশন (Multi-Language Code Tab):**
   - আপনার পছন্দমতো যেকোনো ভাষার কোড দেখতে এবং কপি করতে পারবেন:
     - **C++ (CPP)**
     - **Python**
     - **C#**
     - **Java**
     - **C**
     - **JavaScript**
   - প্রতিটি লাইনে সহজ বাংলা কমেন্ট ও সিনট্যাক্স হাইলাইটিং যুক্ত রয়েছে।

4. **⚡ লাইভ সিঙ্ক্রোনাইজড ট্রেসার:**
   - অ্যানিমেশন চলার সময় C++ ও Python কোডের কোন লাইনটি রান হচ্ছে তা অ্যারো (`►`) দিয়ে হাইলাইট করা হয়।

5. **🌐 বাংলা ও ইংরেজি টগল (`বাং / EN`):**
   - এক ক্লিকেই সম্পূর্ণ ইন্টারফেস বাংলা বা ইংরেজিতে দেখা যায়।

6. **🧠 ইন্টারঅ্যাক্টিভ কুইজ ও কমপ্লেক্সিটি চার্ট:**
   - ভাইভায় আসার মতো সহজ ৩টি কুইজ প্রশ্ন ও Time/Space Complexity চার্ট।

---

## 🚀 কীভাবে রান করবেন (How to Run)

```bash
npm install
npm run dev
```
ব্রাউজারে ওপেন করুন: **`http://localhost:5174/`** (অথবা `http://localhost:5173/`)

---

## 🎮 কী-বোর্ড শর্টকাট (Keyboard Shortcuts)

* **Spacebar** : Play / Pause
* **→ (Right Arrow)** : পরবর্তী ধাপে যাওয়া (Next Step)
* **← (Left Arrow)** : আগের ধাপে ফেরা (Previous Step)
* **R** : শুরুতে রিসেট (Reset)
